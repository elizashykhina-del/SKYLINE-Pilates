SKYLINE PILATES — ІНСТРУКЦІЯ

1. Розпакуй SKYLINE-Pilates.zip на комп’ютері. Для локального перегляду відкрий index.html. Для завантаження шрифтів потрібен інтернет; без нього працюють резервні шрифти.
2. Увійди на https://github.com/ та натисни New repository.
3. Назви репозиторій skyline-pilates. Обери Public і Create repository.
4. Натисни uploading an existing file (або Add file → Upload files).
5. Перетягни ВМІСТ розпакованої папки: index.html, style.css, script.js і папку assets. Не завантажуй ZIP замість файлів. index.html має лежати в корені репозиторію.
6. Натисни Commit changes.
7. Відкрий Settings → Pages. У Build and deployment вибери Source: Deploy from a branch.
8. Обери Branch: main, Folder: /(root), натисни Save.
9. Дочекайся завершення публікації. Посилання з’явиться в Settings → Pages; типовий формат: https://ТВІЙ-ЛОГІН.github.io/skyline-pilates/
10. Відкрий сайт і перевір UA/EN, три вкладки цін, навігацію й форму. Саме GitHub Pages URL додай до слайда 12 лабораторної.
